
# 주니어 백엔드 개발자가 반드시 알아야 할 실무 지식

## 책 소개

『주니어 백엔드 개발자가 반드시 알아야 할 실무 지식』을 읽고 학습한 내용을 기록하는 저장소다.

백엔드 애플리케이션을 개발하고 운영할 때 마주치는 문제를 중심으로 실무 개념을 학습한다. 단순한 기능 구현을 넘어 성능, 장애 대응, 데이터베이스, 외부 연동 등 안정적인 서비스를 만드는 데 필요한 지식을 다룬다.
