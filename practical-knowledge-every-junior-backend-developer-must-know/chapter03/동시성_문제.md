# 🌱 동시성 문제

> 3.3 미리 집계하기 - Column 에서 뻗음
> 상태: 씨앗

## 왜 궁금해졌나

```sql
update survey set answerCnt = answerCnt + 1 where surveyId = 1;
```

5명이 동시에 실행하면 5가 오를 수도, 아닐 수도 있다는데
**"원자적으로 처리되는지 검증하라"는 건 구체적으로 뭘 어떻게 하라는 거지?**

## 파고들 질문

### 기본

- [ ] Race Condition이 정확히 어떤 순서로 발생하나 (타임라인으로)
- [ ] `set cnt = cnt + 1` 과 `읽고 → 계산 → 쓰기` 의 차이
- [ ] 원자적(atomic)이라는 게 정확히 무슨 뜻인가

### 격리 수준

- [ ] READ UNCOMMITTED / READ COMMITTED /
      REPEATABLE READ / SERIALIZABLE — 각각 뭘 막아주나
- [ ] Dirty Read, Non-Repeatable Read, Phantom Read
- [ ] MySQL 기본값은? PostgreSQL은? 왜 다른가

### 잠금

- [ ] 낙관적 락 vs 비관적 락 — 언제 무엇을
- [ ] `select ... for update` 는 언제 쓰나
- [ ] 데드락은 왜 생기고 어떻게 피하나

### 실무

- [ ] **검증은 어떻게 하나?** 동시 요청을 어떻게 재현하지
- [ ] 조회수/좋아요처럼 정확도가 덜 중요한 값과
      재고/잔액처럼 절대 틀리면 안 되는 값의 처리 차이
- [ ] 분산 환경(서버 여러 대)이면 뭐가 더 어려워지나
