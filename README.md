# 책 스터디

매주 정해진 분량을 읽고 발표와 토론을 진행한다.  
발표 자료와 학습 내용은 GitHub에 기록한다.

## 진행 방식

- 매주 **2개 챕터**를 읽는다.
- 스터디원은 총 **4명**이다.
- 매주 **2명이 발표자**를 맡는다.
- 발표자 한 명이 **1개 챕터**를 담당한다.
- 발표자는 담당 챕터의 발표 자료 또는 정리 내용을 GitHub에 기록한다.
- 나머지 인원도 모든 챕터를 읽고 토론에 참여한다.

## 일정

- 일시: **매주 월요일 오후 12시 30분**
- 방식: **오프라인**
- 발표 분량: 매주 2개 챕터

## 역할

### 발표자

- 담당 챕터를 읽고 핵심 내용을 정리한다.
- 오프라인 모임에서 담당 챕터를 발표한다.
- 발표 자료 또는 정리 내용을 GitHub에 올린다.

### 참여자

- 해당 주차의 2개 챕터를 모두 읽는다.
- 질문이나 의견을 준비한다.
- 발표 후 토론에 참여한다.

## 발표 자료 작성 형식

각 챕터의 발표 자료에는 다음 내용을 포함한다.

1. 챕터 핵심 내용
2. 중요 개념과 용어
3. 인상 깊었던 내용
4. 이해하기 어려웠던 부분
5. 실무 또는 개인 경험과 연결되는 내용
6. 함께 토론할 질문
